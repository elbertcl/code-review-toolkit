# Project Agent Instructions

## Memory Vault (READ FIRST)

Persistent memory lives in the Obsidian vault at `~/obsidian-vault`, shared by
opencode, zed, and hermes.

Before starting any task in this project:

1. Read `~/obsidian-vault/wiki/hot.md` (recent context)
2. Read `~/obsidian-vault/wiki/threads.md` (active work — look for this project's threads)
3. Read `~/obsidian-vault/profile/me.md` (owner preferences)

If an active thread matches this project, continue it. When the task completes
or a decision is made, note it in your final summary — the memory system files it.

Write boundaries: in the vault, write ONLY to `wiki/`, `sessions/`,
`wiki/threads.md`, `profile/me.md`. Atomic writes (temp + rename).
