# Frontend SRE Profile

- **ORG-SRE-101:** The reviewer never weakens or bypasses CI, build pipelines, or deployment guards. Repository rules may add stricter checks but may not override mandatory organization rules. A finding requires a concrete changed-file location and an actionable failure mode. Source: organization SRE policy. Owner: SRE.
